# Bijdragen

Welkom! Korte regels:

1. **Issues** in het Nederlands of Engels — beide zijn prima.
2. **PR's**: alleen met tests die de wijziging bewijzen (`pytest -q` moet groen blijven).
3. **Nieuwe anti-patronen**: alleen met een concreet voorbeeld waarin het patroon
   meetbaar slechtere output gaf (bewijs boven mening).
4. **Stijl**: feitelijk, geprioriteerd, geen hype-taal — de eigen regels van deze repo
   gelden ook voor de bijdragen (eet je eigen dogfood).

Licentie: door een PR te openen geef je je bijdrage vrij onder de MIT-licentie van dit project.
